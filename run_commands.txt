E-SKIN 硬件脚本常用命令
======================

工作目录：
D:\OneDrive - Imperial College London\study\Imperial College\BIOE70025 - MSc Major Individual Project 2025-2026\E-SKIN\software-simulation


1. 查看串口
-----------
PowerShell：
.\.venv-record\Scripts\python.exe -m serial.tools.list_ports


2. 记录 FSR + ACC 数据
---------------------
适用固件：
hardware\e-skin_original\src\Eskin\Eskin.ino

PowerShell：
.\.venv-record\Scripts\python.exe tools\record\record.py COM5 16 data_combined.mat --protocol eskin-combined


3. 记录 FSR-only 数据
--------------------
适用固件：
hardware\e-skin_original\src\fsr_adc_plexed_serial\fsr_adc_plexed_serial.ino

PowerShell：
.\.venv-record\Scripts\python.exe tools\record\record.py COM5 16 data_fsr.mat --protocol fsr-serial


4. Python 实时 3D 图
-------------------
适用固件：
hardware\e-skin_original\src\Eskin\Eskin.ino

PowerShell：
.\.venv-record\Scripts\python.exe tools\record\original_scripts\src\Eskin\plot.py COM5


5. MATLAB 实时图，推荐
---------------------
适用固件：
hardware\e-skin_original\src\Eskin\Eskin.ino

MATLAB：
run("D:\OneDrive - Imperial College London\study\Imperial College\BIOE70025 - MSc Major Individual Project 2025-2026\E-SKIN\software-simulation\tools\record\original_scripts\script\serialComEskinCombined.m")

功能：
- 启动后自动采集 100 帧做 tare
- 显示硬件 FPS
- 显示 MATLAB 绘图 FPS
- 显示 FSR layer 1、FSR layer 2、ACC


6. MATLAB FSR-only 图
--------------------
适用固件：
hardware\e-skin_original\src\fsr_adc_plexed_serial\fsr_adc_plexed_serial.ino

MATLAB：
run("D:\OneDrive - Imperial College London\study\Imperial College\BIOE70025 - MSc Major Individual Project 2025-2026\E-SKIN\software-simulation\tools\record\original_scripts\script\serialComFSR.m")

注意脚本里串口应为：
device = serialport("COM5",500000);


7. 第二层灵敏度参数
------------------
文件：
tools\record\original_scripts\script\serialComEskinCombined.m

当前参数：
layer1_gain = 1.0;
layer2_gain = 0.25;
layer1_deadband = 8;
layer2_deadband = 35;

第二层太敏感：
layer2_gain = 0.15;
layer2_deadband = 60;

第二层太迟钝：
layer2_gain = 0.5;
layer2_deadband = 20;


8. 注意
------
- COM5 同一时间只能被一个程序占用。
- 运行 MATLAB 前先关闭 Python 采集脚本。
- 运行 Python 前先关闭 Arduino Serial Monitor。
- 如果 timeout，通常是固件和脚本协议不匹配。
- Eskin 综合模式命令是 0xD0。
