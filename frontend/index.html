Protocol Notes

initial mode
FPGA -> STM32G474
Custom SPI command frame: opcode, module ID, scan mode, frame counter, CRC.
STM32G474 -> MAX11632
MAX11632 setup byte: 0 1 CKSEL1 CKSEL0 REFSEL1 REFSEL0 X X.
MAX11632 conversion byte: 1 CHSEL3 CHSEL2 CHSEL1 CHSEL0 SCAN1 SCAN0 X.
MAX11632 averaging byte: 0 0 1 AVGON NAVG1 NAVG0 NSCAN1 NSCAN0.
MAX11632 reset byte: 0 0 0 1 RESET X X X; RESET=1 clears FIFO, RESET=0 resets registers.
Single-channel command template: 0x80 | (channel << 3) | (scan << 1).
AIN0-AIN15 scan
0xF8 = 1 1111 00 0, scan channels 0 through 15.
ADC result
Each channel returns 0000 + 12-bit code as one 16-bit SPI word.
