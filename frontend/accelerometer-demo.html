Hardware readout demo

4 x 4 LIS3DH Array: CS MUX to STM32G474 to FPGA

A chip-select multiplexer enables one LIS3DH at a time. The MCU sends a datasheet-style SPI command byte, reads OUT_X_L through OUT_Z_H over MISO, decodes X/Y/Z acceleration, then maps vibration intensity from returned register bytes only.

Readout Logic

              one chip per step
            

            
    
              
  • MCU writes A1-A4 to the chip-select MUX.
    • 
              
  • The MUX pulls exactly one LIS3DH CS low.
    • 
              
  • The selected LIS3DH shares SCK, MOSI, and MISO with the full array.
    • 
              
  • MCU sends 0xE8: read bit, auto-increment bit, address 0x28.
    • 
              
  • LIS3DH returns six data bytes for X, Y, and Z acceleration.
    • 
              
  • The heatmap is drawn only from decoded MISO bytes, not from object placement.
