Hardware readout demo

16 x 16 FSR Array: DMUX to ADC to STM32G474 to FPGA

A row-select demultiplexer energizes one FSR row at a time. The ADC is commanded over MOSI to scan AIN0-AIN15, writes SAR results into FIFO, pulls EOC low, then streams FIFO words back to the module MCU. The STM32G474 then sends the raw frame to the upper FPGA/Hub over SPI.

Readout Logic

              one row per step
            

            
    
              
  • MCU sets the DMUX address lines.
    • 
              
  • DMUX drives one row electrode with Vcc.
    • 
              
  • Each column is pulled to ground through 10 kOhm.
    • 
              
  • Pressed FSR cells reduce resistance and raise column voltage.
    • 
              
  • STM32G474 sends MAX11632 conversion command 0xF8, waits for EOC low, then clocks FIFO values out on MISO.
    • 
              
  • Each MAX11632 FIFO result is a 16-bit word: four leading zeros plus the 12-bit ADC code.
    • 
              
  • After a full 16x16 frame, STM32G474 returns raw frame data to the upper FPGA/Hub over SPI.
    • 
              
  • No event-driven encoding or learned encoder is applied in this initial mode.
